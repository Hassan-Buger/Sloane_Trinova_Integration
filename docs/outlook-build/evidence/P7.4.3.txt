Overview
--------
Task P7.4.3 verifies and fortifies the CEO Brain note capture, storage boundary, and opt-in export to TriNova:

1. CEO Brain Local Isolation & Storage Boundary:
   - Private workspace notes are captured with `isPrivate: true`, local timestamp, and stored in `StorageService` (`sloane_brain_v2`).
   - `handleSaveBrain()` in `scripts/app.js` enforces non-empty input validation with helpful warning toast notifications.
   - Private notes are NEVER automatically synchronized to TriNova.

2. AI Privacy Boundary (`PRIVATE_CEO_BRAIN = DENY`):
   - `ContextBuilder.buildContext()` in `server/src/services/ai/contextBuilder.js` unconditionally enforces `privacyAudit.privateCeoBrainDenied: true`.
   - Verified that client context compilation never extracts or includes CEO Brain entries in AI prompts or briefings.
   - Strips any private timeline events or internal notes (`visibility === 'private'`) before AI queries.

3. Opt-in "Send to Trinova" Export Workflow:
   - Export modal (`#trinovaNoteModal`) explicitly presents an unticked confirmation checkbox (`#trinovaNoteConfirm`).
   - `handleSendNoteToTrinova()` strictly halts and alerts if the confirmation box is unchecked.
   - `ApiService.sendNoteToTrinova()` calls `POST /api/v1/companies/:companyId/notes` with `confirm_write_to_trinova: true`.
   - Server route `POST /api/v1/companies/:companyId/notes` strictly requires `confirm_write_to_trinova: true` (returns 422 if omitted), persists note to `mockDb.notes`, and logs an audit event.
   - Creates a `NOTE_CREATED` event on the client timeline and auto-refreshes active views.

4. UI Sanitization & View Hygiene:
   - `renderBrain()` renders entries with `escapeHtml` to prevent XSS.
   - Provides honest empty state when no notes exist (`No private notes in CEO Brain yet. Jot down anything above.`).
   - `openTrinovaNoteModal()` asynchronously populates company selection from live API / cached clients with proper HTML escaping.

5. Bidirectional Sync:
   - Updated `scripts/app.js` and `server/tests/unit27-ceo-brain-notes.test.js` in `Sloane/` mirror.
