Overview
--------
Task P7.4.1 ensures all interactive Client 360 operations work against authenticated, schema-validated REST API endpoints rather than mock state:
1. Client Creation (POST /api/v1/clients):
   - Adds route in `server/src/routes/clients.js` requiring authentication and `sloane:write` scope.
   - Validates client name (returns 400 Bad Request if missing/whitespace).
   - Generates client entity and linked company entity with structured officers (split from comma-separated directors), primary contacts, accounting dates, VAT/PAYE/CIS status, and risk level.
   - Saves entities to `mockDb.clients` and `mockDb.companies`.
   - Records audit action `create_client` on resource `client`.
   - Wired frontend `ApiService.createClient(clientData)` to issue `POST /clients` with `StorageService` cache fallback.
   - Connected `handleSaveClient()` in `scripts/app.js` to create the client via API and refresh clients, businesses, statutory, and command centre.

2. Client Timeline Events (POST /api/v1/clients/:clientId/timeline/events):
   - Authenticated route requiring `sloane:write`.
   - Validates client existence (404 if missing).
   - Validates event payload against schema (`TimelineService.createEvent`), handles deduplication idempotently (200 on duplicate, 201 on new).
   - Wired in `ApiService.createTimelineEvent(clientId, eventData)` and `handleLogTimelineEvent()`.
   - Refreshes both client timeline and notes detail views on completion.

3. Internal Company Notes (POST & GET /api/v1/companies/:companyId/notes):
   - Authenticated routes with role-based visibility filtering (`staff_only` vs `client_visible`).
   - Strict privacy boundary check: requires `confirm_write_to_trinova: true` (returns 422 if unconfirmed).
   - Creating a note automatically triggers a `NOTE_CREATED` timeline event in `TimelineService`.
   - Added `ApiService.getCompanyNotes(companyId)` querying `GET /api/v1/companies/:companyId/notes`.
   - Updated `scripts/app.js` detail renderers: `renderClientNotesDetail`, `renderClientStatutoryDetail`, and `renderClientDocumentsDetail` to query live API endpoints with honest empty states.
   - Updated `handleSendNoteToTrinova()` to refresh active Client 360 notes and timeline on note creation.
