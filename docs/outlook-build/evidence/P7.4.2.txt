Overview
--------
Task P7.4.2 connects the "Add Business Area" interactive feature and business area views directly to authenticated REST API endpoints:

1. Business Areas API Routes (`server/src/routes/businesses.js`):
   - `GET /api/v1/businesses`: Authenticated endpoint requiring `sloane:read` scope. Returns practice business verticals from `mockDb.businesses` enriched with dynamic linked client counts calculated from `mockDb.clients`.
   - `POST /api/v1/businesses`: Authenticated endpoint requiring `sloane:write` scope.
     - Validates presence of `name` and `type` (returns 400 Bad Request with structured code if missing or whitespace).
     - Checks for duplicate business names (case-insensitive, returns 409 Conflict).
     - Generates unique ID (`biz-${Date.now()}`), sets status to 'Active', and appends to `mockDb.businesses`.
     - Records audit log action `create_business_area` on resource `business_area`.
     - Returns 201 Created with `{ status: 'success', data: newBiz }`.

2. App Router Mounting (`server/src/app.js`):
   - Mounted `registerBusinessRoutes(app, { authenticate, requireScope })`.
   - Added initial practice business areas (`INITIAL_BUSINESSES`) to `mockDb` in `server/src/data/db.js`.

3. Frontend Services & UI Integration (`scripts/services/api.js` & `scripts/app.js`):
   - `ApiService.getBusinesses()`: Queries `GET /api/v1/businesses`, caches results in `StorageService`, and gracefully falls back to cached data if offline.
   - `ApiService.createBusiness(bizData)`: Issues `POST /api/v1/businesses` with body, updates `StorageService` cache upon success, and falls back gracefully.
   - `scripts/app.js`:
     - `renderBusinesses()`: Renders active business cards with dynamic linked client counts and includes an honest empty state (`No active business areas configured. Click "+ Add Business Area" above to create one.`).
     - `populateClientModalBizSelect()`: Asynchronously fetches latest business areas from `ApiService.getBusinesses()` so newly created business areas appear immediately in the "Add Client" business area select dropdown.
     - `handleSaveBiz()`: Creates business area via `ApiService.createBusiness()`, closes modal, shows success toast, and refreshes business cards, command centre, and client modal dropdowns.

4. Bidirectional Sync:
   - Mirrored all updated files into `Sloane/` (`server/src/routes/businesses.js`, `server/src/app.js`, `server/src/data/db.js`, `scripts/services/api.js`, `scripts/app.js`, `server/tests/unit26-business-areas-api.test.js`).
