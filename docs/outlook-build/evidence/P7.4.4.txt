Overview
--------
Task P7.4.4 verifies and fortifies the Ask Sloane AI assistant query pipeline, Claude server-side service, grounded fallback, and provenance tracking:

1. Server-Side AI Assistant & Privacy Boundary:
   - Route `POST /api/v1/ai/ask` strictly requires bearer authentication (`sloane:read`) returning 401 for unauthenticated requests.
   - Enforces sliding-window rate limiting (Section 38) returning 429 when limits are exceeded.
   - Input validation: rejects empty or whitespace queries with 422 (`VALIDATION_FAILED`), rejects queries >1000 characters with 422 (`MESSAGE_TOO_LONG`), and non-existent `clientId` with 404 (`CLIENT_NOT_FOUND`).
   - Multi-turn conversation history is sanitized: capped at 10 items, role constrained to user/assistant, content length limited.
   - `ContextBuilder.buildContext` unconditionally enforces `privateCeoBrainDenied: true` across both client-specific and practice-wide queries, strictly isolating client contexts and never leaking CEO Brain private notes.
   - `GET /api/v1/ai/models` and `GET /api/v1/ai/executive-briefing` provide verified diagnostic and morning executive briefing data with audit tags.

2. Client-Side ApiService & Provenance Truthfulness:
   - `ApiService.request` now preserves the full response `raw` envelope alongside unwrapped `data`.
   - `ApiService.askAi` calls backend `POST /api/v1/ai/ask`, faithfully extracting `source` and `model` from the response envelope.
   - When backend is offline or errors, seamlessly engages `runGroundedFallback` which truthfully reports `source: 'offline_rules_engine'` and NEVER fabricates live Claude or Gemini status.
   - Answers conversational inputs naturally and calculates math directly without false risk cards.

3. Frontend UI Implementation & XSS Sanitization:
   - `scripts/app.js` `handleAskSloane` maintains ongoing dialogue via `this.aiConversationHistory` across initial query and modal follow-ups (`#aiModalReplyForm`).
   - Provenance badges truthfully indicate engine: `⚡ Claude 3.5 Sonnet`, `✨ Google Gemini`, or `🛡️ Offline Grounded Fallback`.
   - Comprehensive XSS escaping applied:
     - `escapeHtml(data.answer)` with formatted paragraph/break restoration (`<br><br>`, `<br>`).
     - `escapeHtml(r)` for key drivers & evidence list.
     - `escapeHtml(act.action)` and `escapeHtml(act.priority)` for recommended next actions.
     - `escapeHtml(ev.reason)` and `sanitizeId(ev.timeline_event_id)` for grounded provenance citations.
   - `jumpToTimelineEvent` closes modal, sets `this.activeClient360Id`, switches view to `clients`, switches tab to `timeline`, loads timeline records, and smoothly scrolls to and highlights target timeline event with `.highlighted-event`.

4. Static Shell Leak & Security Hygiene:
   - `index.html` static logged-out shell contains zero literal `@` symbols and zero sensitive client entities (`woofington`, `jenkins`, `alpha delta`, `cfi awarding`, `r gb`, `kirsty`).
   - Accessible modal structure verified: `#aiResponseModal`, `#aiModalBody`, `#aiModalReplyForm`, `#aiModalReplyInput`, `#modalAiProviderSelect`.

5. Bidirectional Sync:
   - Synchronized `scripts/app.js`, `scripts/services/api.js`, and `server/tests/unit28-ask-sloane-api.test.js` between root repository and `Sloane/` mirror.
